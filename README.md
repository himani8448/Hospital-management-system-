# # Hospital Management System

## Project Description
This is a simple Hospital Management System developed using HTML, CSS, and Node.js. It allows users to register patients and view patient records. The patient data is stored in a JSON file.

## Features
- Patient Registration
- View All Patients
- Stores patient details in JSON
- Simple and user-friendly interface

## Technologies Used
- HTML
- CSS
- Node.js
- JavaScript
- File System (fs)

## Project Structure
```
Hospital-Management-System/
│── index.html
│── style.css
│── server.js
│── patients.json
│── README.md
```

## How to Run
1. Install Node.js.
2. Open the project folder.
3. Run the command:
   ```bash
   node server.js
   ```
4. Open your browser and visit:
   ```
   http://localhost:3000
   ```
